# LearnPath — Personalized Learning App

Tell it what you want to learn, chat to refine focus, take a 10-question adaptive quiz, and get a curated study plan of **free** courses from MIT OpenCourseWare, Stanford, Harvard, IIT/NPTEL, Princeton, and more.

- **Frontend:** React + Vite + TypeScript + Tailwind + Framer Motion (dark, glassmorphic UI)
- **Backend:** FastAPI (Python venv) proxying Azure OpenAI + Supabase
- **Auth:** Supabase magic-link email
- **Storage:** Supabase (`learning_sessions` table)
- **Courses:** MIT Learn public API (live) + hand-curated Stanford/Harvard/IIT/Princeton list

## Setup

### 1. Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# edit .env and fill in AZURE_OPENAI_*, SUPABASE_*
uvicorn app.main:app --reload --port 8000
```

Health check: <http://localhost:8000/health>

### 2. Frontend

```bash
cd frontend
npm install
cp .env.example .env
# edit .env: VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY
npm run dev
```

Open <http://localhost:5173>.

### 3. Supabase

1. Create a project at [supabase.com](https://supabase.com).
2. In the SQL editor, paste and run `supabase/schema.sql`.
3. In **Authentication → Providers**, enable **Email** (magic link is default).
4. Copy from **Project Settings → API**:
   - `URL` → `SUPABASE_URL` (backend) + `VITE_SUPABASE_URL` (frontend)
   - `anon` key → `VITE_SUPABASE_ANON_KEY` (frontend)
   - `service_role` key → `SUPABASE_SERVICE_ROLE` (backend only, keep secret)

### 4. Azure OpenAI

In the Azure portal, deploy a chat model (recommended: `gpt-4o` or `gpt-4o-mini`). Then set in `backend/.env`:

```
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com/
AZURE_OPENAI_KEY=<key>
AZURE_OPENAI_DEPLOYMENT=<your-deployment-name>
AZURE_OPENAI_API_VERSION=2024-08-01-preview
```

## Flow

1. **Tab 1 — What to learn**: user picks subjects (chips + custom), months, hours/day, optional goal.
2. **Tab 2 — Refine focus (chat)**: Azure OpenAI asks 2–4 targeted questions to discover focus areas, background, outcome. When ready it emits `ready_for_assessment: true` and moves on automatically.
3. **Tab 3 — Quick quiz**: 10 MCQs generated by Azure OpenAI, mixing beginner/intermediate/advanced, tailored to the focus areas.
4. **Tab 4 — Your path**: level (beginner/intermediate/advanced), strengths, gaps, weekly plan, and a curated list of free courses from MIT Learn API + curated catalog. LLM picks only from real URLs — no hallucinations.

## API endpoints

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/chat` | Multi-turn refinement; returns next assistant message + focus areas |
| POST | `/api/assessment` | Generates 10 MCQs |
| POST | `/api/score` | Grades + returns level + curated free courses |
| GET  | `/health` | Config status |

## Notes

- Keys never leave the backend. Frontend only holds the Supabase anon key + backend URL.
- MIT courses are fetched live from `https://api.learn.mit.edu/api/v1/courses/`.
- Curated Stanford / Harvard / IIT / Princeton list is in `backend/app/catalog.py` — extend as you wish.
- To skip auth for local testing, just don't sign in; the app still works with an anonymous session ID.
